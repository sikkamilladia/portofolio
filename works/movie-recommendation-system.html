Movie Recommendation System

2024 · Mini Project · Python, Streamlit, TF-IDF, SVD

Overview

A simplified movie recommender that implements two classic approaches side by side. It is built as a study-friendly project: it ships with a tiny sample dataset so it runs right away, and it can be switched to a larger dataset such as MovieLens later.

What I did

  • Built content-based filtering using TF-IDF on movie genres and cosine similarity.
  • Built collaborative filtering using a truncated SVD on a user–item rating matrix.
  • Added a command-line entry point and a minimal Streamlit interface.
  • Organized the code into separate modules for data preparation and each method.

Result

A working recommender that gives movie suggestions from either method. I learned how content-based and collaborative filtering differ: one compares movie features, the other compares users' rating patterns.
