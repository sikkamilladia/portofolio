Tide Table

2026 · Solo project · HTML, CSS

Overview

Tide Table shows the next seven days of tides and sunrise times on a single printable page. It is meant for sailors who plan a weekend trip and want to check conditions at a glance.

What I did

  • Interviewed three sailors about what they check before leaving.
  • Sketched the layout on paper, then built it in plain HTML and CSS.
  • Tested printing on A4 so it fits on one sheet.
